# Inbox: proposed skill changes

Lessons from projects land here as proposals, written by `tahi-core:retro` (or by hand). Skills are never edited mid-project on a hunch; changes are reviewed here once a month.

One file per proposal: `YYYY-MM-DD-{project}-{topic}.md`

```markdown
## {date} · {project} · {skill name}
Problem: what happened, with the evidence.
Proposed change: the rule to add, change or delete, word for word.
Scope: which levels or stacks it applies to (tags).
```

## Monthly review

For each proposal: merge it into the one skill that owns the rule (never copy a rule into two skills), reject it, or leave it for more evidence. Delete the file once it is merged or rejected, add a line to `CHANGELOG.md`, and run the evals for any plugin you changed.
